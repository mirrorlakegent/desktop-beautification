## M4-B v8 七轮修复（e793440）—— 终版布局模式
- 用户 v7 复验：中文乱码已修，但 **2 项长期问题仍未解决**：
  1. **调节滑块文字/数值显示不全**：弹窗用固定假设 TrackBar 高度(38px) 推进 Y 光标，
     用户系统 DPI 下 TrackBar 实际更高 → 后续控件被上移/重叠/裁切
  2. **emoji 与文字离这么远**：FenceLayer 用 GDI+ DrawString 分字体画 emoji+标签，
     靠 MeasureString 测宽度手工偏移；GDI+ 对 emoji 返回字体** advance 宽度(含巨大侧边距)**，
     偏移失控
- **根因级修复（本会话关键经验）**：
  - 弹窗布局：**Y 光标一律按控件真实 `ctl.Bottom` 推进**（`y = ctl.Bottom + gap`），
    绝不假设 TrackBar/CheckBox 等控件高度；数值标签 `AutoSize` 右对齐跟随滑块行；
    窗体 `AutoScaleMode=Dpi` 适配高 DPI
  - 标题绘制：**改用 GDI `TextRenderer.DrawText`**（非 GDI+ DrawString）——自动字体
    fallback 到 Segoe UI Emoji 彩色字形、一次绘制 emoji+中文、间距天然正确
- 编译 0 错误，发布 ds2，双远程推送成功（9ef5135..e793440）
- 根因已根治，待用户重启复验确认

## M4-B v8 九轮修复（2d4ef62）—— 透明度失效
- 用户 v8 复验：弹窗布局/emoji/按钮均 ✅，但**透明度调节完全失效**
  - 围栏几乎不可见：主体完全透明、标题栏完全不透明
- **根因**：`settings.json` 存了之前某轮迭代保存的**极端脏数据**
  （BodyOpacity=0, HeaderOpacity=255, CornerRadius=40, FrostOpacity=0）
  `AppSettings.Load()` 反序列化后无任何 clamp → 脏值直接传入渲染管线
- **修复**：
  1. `AppSettings.Load()` 加 `Math.Clamp`（体≥40, 头≥80, 字号8-28 等）
  2. `FenceLayer.SetAppearance()` 加防御性 clamp（双重保险）
  3. 用户本地 `settings.json` 已立即修正为正常默认值
