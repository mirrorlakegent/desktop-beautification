### M3.25 — 图标渲染三处根因修复（11:33）
1. **图标句柄生命周期（主因）**：`Icon.FromHandle(hIcon)` → `Clone()` → `Dispose()` 模式，
   Clone 与原件共享同一 HICON，原件 Dispose 后缓存 Clone 句柄失效 → `DrawIcon` 静默无输出。
   修复：HICON→`Icon.ToBitmap()` 深拷贝像素 + `DestroyIcon` 释放，缓存 `Bitmap` 而非 `Icon`。
2. **系统图标缺 SHGSI_ICON 标志**：改为 `SHGSI_ICON|SHGSI_LARGEICON`。
3. **alpha 预乘**：GDI+ `Format32bppArgb` 是 straight-alpha，但 `UpdateLayeredWindow`+`AC_SRC_ALPHA`
   要求 premultiplied(PARGB)。新增 `PremultiplyAlpha` 在 `GetHbitmap` 前原地预乘。
- Commit `e7800a0`
