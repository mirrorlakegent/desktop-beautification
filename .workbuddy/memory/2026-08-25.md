## v20 修复：消息专用窗口替代 SystemEvents
- **方案**：创建隐藏 `HWND_MESSAGE` 消息专用窗口（parent=HWND_MESSAGE），直接接收 OS 原生
  `WM_SETTINGCHANGE` 广播（子窗口收不到的、SystemEvents 抽象层可能丢失的，它都能收到）；
  当 `wParam == SPI_SETDESKWALLPAPER` 时 `PostMessage(WM_FROST_REFRESH)` 回围栏窗口线程重捕壁纸。
- **改动**：
  - `NativeMethods.cs`：新增 `WM_SETTINGCHANGE`(0x001A) + `HWND_MESSAGE`(-3) 常量。
  - `FenceLayer.cs`：删除 `SystemEvents.UserPreferenceChanged` 订阅（v19 不可靠）；
    新增 `_frostListenerHwnd` + `FrostListenerWndProc`（消息专用窗口 WndProc，仅处理 WM_SETTINGCHANGE）；
    `HookSystemEvents()` 改为 RegisterClassEx + CreateWindowEx(HWND_MESSAGE) 创建监听窗口；
    `UnhookSystemEvents()` 改为 DestroyWindow 监听窗口。
- 编译 0 错误；发布 ds2（exe Aug 25 23:29）。提交 + 双远程推送 v20（待 commit/push）。
