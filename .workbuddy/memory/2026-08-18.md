## DesktopSuite.exe 打不开故障排查（22:09 反馈）
- **现象**：用户反馈 `D:\WorkBuddy\ds2\DesktopSuite.exe` 打不开。
- **根因**：单实例互斥锁被**残留进程占用**。本机存在 PID 12396（同路径 exe，22:17 启动）后台
  驻留——本程序关窗口 = 隐藏到托盘、进程不退出（ShutdownMode.OnExplicitShutdown）。用户双击
  新实例时，新实例检测到 live mutex → 仅发 show event 激活旧实例并退出，而旧实例窗口状态异常
  未显示 → 看起来"打不开"。
- **验证**：干净状态（无旧实例）下用 PowerShell 启动该 exe，进程正常 ALIVE（PID 5352 / 2760），
  说明 exe 本身与 .NET 8 桌面运行时均正常，非代码崩溃或运行时损坏。
- **解决**：① PowerShell 结束所有 DesktopSuite 进程解除锁；② 重新发布最新代码到 ds2：
  `dotnet publish -c Release -r win-x64 --no-self-contained -o 'D:\WorkBuddy\ds2'`
  （务必用 PowerShell 或单引号！Git Bash 下 `/d/...` 会被当成相对路径变成 `D:\d\...`，
  双引号里的反斜杠会被转义破坏路径）；③ 验证启动成功。
- **用户指引**：关窗口是隐藏到托盘（单实例驻留），再开时激活托盘实例；若窗口不出现，点托盘
  图标即可，或任务管理器结束 DesktopSuite 进程再开。
- **加固待办（未做）**：当前单实例逻辑在"旧实例卡死/窗口失效且不响应 show event"时，新实例
  会退出导致永久打不开。若用户再遇此问题，应改为：发 show event 后超时无响应则强制结束旧实例
  并自行接管。
