## M3.7 拖拽修复：重叠 + 落点检测（08:35）

### 用户反馈
1. 分类交换位置后仍然重叠
2. 拖动时必须拖到标题栏才生效，拖到盒子里没效果（分类重排 + 条目拖拽均如此）

### 根因分析
**问题1 重叠**：
- 旧逻辑用被拖盒子的**中心点**判断是否落在目标盒内 → 大盒子拖到小盒子上时中心可能不在目标内 → 不触发交换 → 盒子停在重叠位置
- 即使触发交换，大盒子放到小盒子的坐标会因尺寸差溢出重叠

**问题2 只有标题栏生效**：
- 分类重排：用"盒子中心在目标内"判断 → 落在目标 body 区但中心在外则不触发
- 条目拖拽：HitTest 对网格间隙可能返回 None → 需要矩形包含兜底

### 修复（FenceLayer.cs EndDrag）
1. **落点检测改为 `BoxesOverlap(a, b, 0.3f)`**：两盒面积重叠 >30% 即触发交换（不再依赖中心点）
2. **新增 `SeparateOverlappingBoxes()`**：交换后最多 5 轮碰撞分离——沿最小重叠轴推开，保持 minGap=8px 间距
3. **新增 `BoxesOverlap()` 辅助方法**：计算两矩形交集面积占较小矩形比例
4. **条目拖拽加矩形兜底**：HitTest 返回 None 时逐个检查 `_boxRects` 矩形包含关系

### 技术细节
- 分离方向取 overlapX vs overlapY 的较小者（沿最小穿透轴推）
- 坐标转换：物理像素 delta / _dpiX → 逻辑像素写入 cat.X/Y

## M3.13 代理窗口白屏修复（10:08）

### 用户反馈
"一点桌面图标就满屏白，还不能拖到窗口里"

### 根因分析
**三个 bug 叠加导致全屏白色覆盖：**

1. **WS_EX_LAYERED 窗口未预设透明内容就 ShowWindow(SW_SHOW)**：
   - `ShowProxy()` 先调 `ShowWindow(SW_SHOW)` 再调 `RenderHighlight()`

   - 窗口是全屏 TOPMOST → 整个屏幕被刷白

2. **创建窗口时从未调用 UpdateLayeredWindow 设置初始透明状态**：
   - WS_EX_LAYERED 只声明"这个窗口支持分层透明"
   - 不调用 UpdateLayeredWindow → Windows 用默认不透明内容填充

3. **拖拽阈值太低（6px）**：
   - 点击图标时鼠标微抖 >6px 就触发 `_dragging=true` + `ShowProxy()`
   - 用户感觉"一点就白"

### 修复（FenceDropProxy.cs）
1. **新增 `SetProxyTransparent()` 方法**：用 1x1 全透明 bitmap 调 UpdateLayeredWindow，在 CreateProxyWindow() 末尾调用一次 → 窗口创建即透明
2. **`ShowProxy()` 改为先 RenderHighlight 再 ShowWindow**：确保显示时已有正确的透明内容
3. **`HideProxy()` 隐藏后重置为全透明**：下次 Show 从干净状态开始
4. **拖拽阈值 6px → 16px**（36 → 256 平方像素）：减少误触
