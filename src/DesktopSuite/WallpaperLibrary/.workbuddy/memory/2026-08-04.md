## 关键经验 / 坑
- ImageGen / VideoGen 为延迟工具，需先 ToolSearch 取 schema 再 DeferExecuteTool；output_dir 支持中文路径。
- 沙箱 safe-delete 会拦截删除：python os.remove 抛 SAFE_DELETE_FAIL_CLOSED，bash rm -rf 触发 SAFE_DELETE_BULK_REJECTED 且用户拒绝；临时目录 .ai_cache 残留需用户手动清理。
- Commons 视频源在部分环境被限流，动态壁纸优先用 AI 生成更稳妥。
- 网络下载静态图用 Commons API（commons.wikimedia.org/w/api.php）搜索 + curl -L 下载 upload.wikimedia.org 原图，比 urllib 更稳（urllib 曾被 403）。
