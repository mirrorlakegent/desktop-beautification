- 中文名；首次启用或"打开文件夹"时由 `EnsureLibraryExists()` 创建，每时段附 `把壁纸放进这里.txt` 提示。
- 某时段两子目录皆空 → 跳过该时段，不影响其他时段；全部为空 → 轮换静默跳过、保留当前壁纸。

### 随机算法（无短时重复）
- 每时段维护一个洗牌队列；取完即重新洗牌；若仅有多张且本次等于上一张，则换下一张（单张时无法避免重复，属正常）。

### 静态 vs 动态统一
- 两者均经 `WallpaperEngine.StartDynamic(path, audioEnabled:false, volume:0)` → mpv 嵌 WorkerW（图标后）。
- 静态图复用 mpv 的 `--image-display-duration=inf`（已在 `MpvHost` 内置），无需额外分支；库轮换默认静音。
- 既有的 `SetStatic`（Win32 SPI，图标前）路径**未改动**，仅用于主窗口"Set Static Wallpaper"手动按钮。

### 调度与生命周期
- `System.Timers.Timer`（AutoReset），间隔 = `RotationIntervalMinutes × 60000`（5–120 分钟）。
- 启用时立即在后台线程应用当前时段一张（避免阻塞 UI 线程的 ~1.2s 渲染就绪等待）。
- 定时器随 `MainWindow` 生命周期：`OnClosed` 中 `Dispose()` 停表；壁纸渲染进程保持 detached（关 GUI 仍在播）。
- 轮换会接管/重启渲染进程（先 `StopByPid(保存的PID)`，再 `StartDynamic`），并回写 `LastMedia/RendererPid`。

### 设置持久化（AppSettings 扩展）
- 新增 `RotationEnabled`、`RotationIntervalMinutes`(默认30)、`LibraryPath`(默认空→解析为 `AppContext.BaseDirectory/WallpaperLibrary`)。

### UI / 托盘落点
- 主窗口新增 **"Wallpaper Library / 壁纸库"** 分组：启用开关、间隔滑块(5–120)+标签、立即轮换、打开文件夹、状态文本。
- 托盘菜单新增 **"🖼️ 立即轮换壁纸"**（调用 `MainWindow.RotateNow()`）。
