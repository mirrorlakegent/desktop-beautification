启动方法

等待约 10-15 秒，看到 llama_server: listening 表示启动成功。

2

在 WorkBuddy 中切换到自定义模型即可开始对话。

验证服务：浏览器打开 http://127.0.0.1:8080 可看到聊天测试界面。

启动脚本内容

:: D:\llama\启动7B模型-RTX2070优化.bat
@echo off
chcp 65001 >nul
title Qwen2.5-7B-Instruct (RTX 2070 优化版)
cd /d "%~dp0"

llama-server.exe ^
    -m "models\qwen2.5-7b-instruct-q4_k_m.gguf" ^
    -ngl 99 ^
    -c 65536 ^
    -n 8192 ^
    --cache-type-k q8_0 ^
    --cache-type-v q8_0 ^
    --flash-attn on ^
    --no-repack ^
    -np 1 ^
    --host 127.0.0.1 ^
    --port 8080
pause

参数说明

参数含义为什么这样设
-ngl 99全部层卸载到 GPU7B 模型 4.36GB 完全放入 8GB 显存
-c 65536上下文窗口 65536 tokensWorkBuddy 请求约 50K tokens，需大于此值
-n 8192最大生成 8192 tokens足够长的回复
--cache-type-k/v q8_0KV 缓存 Q8 量化节省约 50% 显存，几乎不影响质量
--flash-attn onFlash Attention长上下文 prompt 处理速度提升 2 倍
--no-repack禁用 CPU 权重重排GPU-only 模式不需要，避免 3GB 额外内存占用
-np 1单并行槽独占显存给单个请求，避免多槽争抢

CUDA 修复记录（已解决）

问题：ggml-cuda.dll (564MB) 无法加载，llama-bench 只识别 CPU 后端，WorkBuddy 请求超时无响应。

根本原因：系统未安装 CUDA Toolkit，缺少 cublas64_12.dll 和 cublasLt64_12.dll。

修复步骤：

  1. 用 pefile 分析 ggml-cuda.dll 导入表，确认缺少 cublas64_12.dll
  2. 从清华 PyPI 镜像安装 nvidia-cublas-cu12（553MB，9 秒下完）：
    pip install nvidia-cublas-cu12 -i https://pypi.tuna.tsinghua.edu.cn/simple --no-deps --target C:\cuda_dlls_temp
  3. 提取 DLL 文件复制到 D:\llama\：
    cublas64_12.dll (102 MB) + cublasLt64_12.dll (668 MB)
  4. 验证：ggml-cuda.dll 加载成功，CUDA 后端正常
清理提示：临时目录 C:\Users\USER\cuda_dlls_temp（约 770MB）可手动删除以回收磁盘空间。

常见问题

Q: 启动后对话没有回应

检查命令行窗口是否出现 CUDA0 字样。如果只看到 CPU 后端，说明 CUDA 未加载——检查 cublas64_12.dll 和 cudart64_12.dll 是否在 D:\llama\ 目录中。

Q: 报错 "failed to allocate CPU_REPACK buffer"

系统内存不足导致 CPU 权重重排失败。启动脚本已包含 --no-repack 参数禁用此功能（GPU 模式下不需要）。如果仍报错，关闭一些占内存的程序后重试。

Q: 报错 "exceeds the available context size"

WorkBuddy 发送的请求约 50K tokens，上下文必须设为 -c 65536。同时在 WorkBuddy 模型设置中将「输入上下文」也设为 65536。

Q: 显存不够 (OOM)

当前配置已优化：模型 4.36GB + KV 缓存（Q8 量化）~2GB = ~6.4GB，加上 CUDA 开销约 7.5GB，刚好在 8GB 内。如果仍 OOM，可将 -c 降到 32768。

Q: 首次对话很慢，后续很快

首次请求需要处理完整 system prompt（约 50K tokens），耗时约 30-60 秒。后续请求可命中 KV 缓存，仅需数秒。这是正常行为。

Q: 想换更强的模型

RTX 2070 8GB 显存上限：7B Q4_K_M (4.4GB) 是最佳选择。14B Q3 约 6.8GB 会挤满显存导致上下文不足。如需更强模型，建议升级到 12GB+ 显存的 GPU。

Q: 关闭窗口后服务断开

命令行窗口必须保持开启。可以最小化但不能关闭。如需后台运行，可用 pythonw 或 Windows 任务计划程序。
